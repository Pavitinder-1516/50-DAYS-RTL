# Day 11 — 4-bit Ripple Carry Adder

## Objective

The objective of Day 11 is to understand and implement a **4-bit Ripple Carry Adder (RCA)** using Verilog.

A Ripple Carry Adder combines multiple Full Adders to perform multi-bit binary addition. The carry generated by each stage propagates to the next stage.

## 1. What Is a Ripple Carry Adder?

A Ripple Carry Adder adds two binary numbers of multiple bits.

For a 4-bit design, the inputs are:

- `A[3:0]` — First 4-bit number
- `B[3:0]` — Second 4-bit number
- `Cin` — Initial carry input

The outputs are:

- `Sum[3:0]` — 4-bit sum
- `Cout` — Final carry output

```text
 A[0]  B[0]       A[1]  B[1]       A[2]  B[2]       A[3]  B[3]
   │     │           │     │           │     │           │     │
   ▼     ▼           ▼     ▼           ▼     ▼           ▼     ▼
 ┌─────────┐       ┌─────────┐       ┌─────────┐       ┌─────────┐
 │  Full   │ c1    │  Full   │ c2    │  Full   │ c3    │  Full   │
 │ Adder 0 ├──────►│ Adder 1 ├──────►│ Adder 2 ├──────►│ Adder 3 │
 └────┬────┘       └────┬────┘       └────┬────┘       └────┬────┘
      │                 │                 │                 │
    Sum[0]            Sum[1]            Sum[2]            Sum[3]

 Cin ──► First Full Adder                         Final carry ──► Cout
```

Each Full Adder calculates one sum bit and generates a carry for the next stage.

## 2. Working Principle

The addition starts from the least significant bit (LSB).

1. The first Full Adder adds `A[0]`, `B[0]`, and `Cin`.
2. Its carry output becomes the carry input of the second Full Adder.
3. The process continues through all four stages.
4. The last Full Adder generates `Sum[3]` and the final `Cout`.

The carry propagates through the stages, which gives the circuit its name.

## 3. Mathematical Representation

For each bit position \(i\):

**Sum**

```text
Sum[i] = A[i] XOR B[i] XOR C[i]
```

**Carry**

```text
C[i+1] = (A[i] & B[i]) |
         (A[i] & C[i]) |
         (B[i] & C[i])
```

Here, `C[0] = Cin` and `C[4] = Cout`.

The final result is:

```text
{Cout, Sum} = A + B + Cin
```

## 4. Example

Consider:

```text
A   = 0101  (5)
B   = 0011  (3)
Cin = 0
```

The addition is:

```text
   0101
 + 0011
 -------
   1000
```

Expected outputs:

```text
Sum  = 1000
Cout = 0
```

The result is 8, represented by the 4-bit sum `1000`.

Another example demonstrates the final carry:

```text
A   = 1111  (15)
B   = 0001  (1)
Cin = 0
```

Expected outputs:

```text
Sum  = 0000
Cout = 1
```

The complete result is `{Cout, Sum} = 10000`, which represents 16.

## 5. RTL Implementation

The RTL file is located at:

```text
rtl/ripple_carry_adder.v
```

The design can be implemented by connecting four Full Adder modules in sequence.

Each stage receives:
- One bit from `A`
- One bit from `B`
- The carry from the previous stage

The first stage receives `Cin`, and the final stage produces `Cout`.

This modular approach encourages **RTL reuse**, because the Full Adder designed on Day 10 can be reused instead of rewriting its internal logic.

## 6. Testbench and Verification

The testbench is located at:

```text
tb/ripple_carry_adder_tb.v
```

The testbench should verify:

- Addition of zero and zero
- Addition of small binary numbers
- Addition with `Cin = 1`
- Carry propagation across multiple stages
- Generation of the final carry
- Maximum input values

For exhaustive verification, all combinations of `A`, `B`, and `Cin` can be tested.

There are:

```text
2^4 × 2^4 × 2 = 512 combinations
```

The expected result should be compared against:

```verilog
{cout, sum} == (a + b + cin)
```

Use a sufficiently wide reference expression in the testbench to avoid truncating the expected result.

## 9. Advantages and Limitations

### Advantages

- Simple architecture
- Easy to implement in RTL
- Reuses the Full Adder module
- Supports multi-bit binary addition

### Limitations

- Carry must propagate through successive stages.
- Propagation delay increases as the number of bits increases.
- Larger adders can be slower than architectures that calculate carries more efficiently.

## 11. Real-World Applications

Ripple Carry Adders are useful in:

- Arithmetic Logic Units (ALUs)
- Small processors
- Counters
- Address-generation circuits
- Arithmetic datapaths
- FPGA and ASIC digital designs

## Key Takeaway

A **Ripple Carry Adder adds multi-bit binary numbers by passing the carry from one Full Adder stage to the next**.

Its key characteristic is that carry propagation creates a delay that grows with the number of bits.
